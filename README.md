# Bookia

Bookia is a Flutter e-commerce app for browsing and buying books. It includes authentication, home discovery, search, wishlist, cart, checkout, profile management, and bilingual localization (English/Arabic).

## Features

- **Authentication flow**
  - Login, registration, forgot password, email verification, reset password.
- **Home experience**
  - Sliders, categories, best-seller/new-arrival products.
- **Search**
  - Product search page with dedicated state management.
- **Product details**
  - Full product details screen.
- **Wishlist & Cart**
  - Add/remove wishlist items and cart management.
- **Checkout**
  - Checkout form and order placement flow.
- **Profile**
  - View and edit profile.
- **Localization**
  - English (`en`) and Arabic (`ar`) via `easy_localization`.
- **Responsive UI**
  - Uses `flutter_screenutil` with a 375x812 reference design.

## Tech Stack

- **Framework:** Flutter (Dart)
- **State Management:** `flutter_bloc`
- **Networking:** `dio`
- **Persistence:** `shared_preferences`, `flutter_secure_storage`
- **Localization:** `easy_localization`
- **UI utilities:** `flutter_svg`, `google_fonts`, `carousel_slider`, `skeletonizer`

## Project Structure

```text
lib/
  core/               # routing, networking, shared utilities/widgets
  features/
    auth/             # login/register/forgot/reset/verify
    home/             # home data + UI
    search/           # search logic + UI
    product/          # product details
    wishlist/         # wishlist state + UI
    cart/             # cart state + UI
    checkout/         # order/checkout flow
    profile/          # profile and editing
    splash/           # splash page
```

## API

The app uses this backend base URL:

- `https://codingarabic.online/api`

Endpoints are organized in `lib/core/network/api_constants.dart`.

## Getting Started

### Prerequisites

- Flutter SDK (compatible with Dart `^3.11.0`)
- Android Studio / VS Code with Flutter plugins
- Android/iOS emulator or physical device

### Installation

1. Clone the repository:

   ```bash
   git clone <your-repo-url>
   cd bookia
   ```

2. Install dependencies:

   ```bash
   flutter pub get
   ```

3. Run the app:

   ```bash
   flutter run
   ```

## Routing

Initial route: `/` (Splash screen).

Main routes include:

- `/login`
- `/register`
- `/forgot-password`
- `/verify-code`
- `/reset-password`
- `/home`
- `/search`
- `/product-details`
- `/cart`
- `/checkout`
- `/profile`
- `/edit-profile`

Defined in `lib/core/app_routes/app_routes_name.dart` and generated by `lib/core/app_routes/route_generator.dart`.

## Notes

- This project is configured as a private app (`publish_to: 'none'`).
- Generated assets helper is configured through `flutter_gen` (`lib/core/generated/`).
